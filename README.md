## 📖 About The Project

**HOPE** is an enterprise management suite built for agile, scalable operations. It unifies essential corporate departments into a single, cohesive workspace with role-based access controls and responsive dashboards:

- 👥 **Human Resources (HR)**: Employee directory, role assignments, onboarding, and departmental records.
- 💼 **Sales & Transactions**: Pipeline tracking, sales deal flows, and transaction logs.
- 🤝 **Customer Relationship Management (CRM)**: Contact profiles, customer engagement history, and lifecycle status.
- 📦 **Product & Inventory**: Catalog management, SKU listings, and inventory tracking.
- 🛡️ **User Management & Safeguards**: Granular permission dialogs, role hierarchies (Superadmin, Admin, Member), and audit trails.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [pnpm](https://pnpm.io/) or `npm`

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Pampanga-West/baikolano-website.git
   cd baikolano-website/frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch development server:
   ```bash
   npm run dev
   ```
